THE WEDNESDAY EDITION — a broadsheet of Tuesday 24 November 2026. 40
stories, all hard news (war, trade, disaster, politics) whose events
happened on 24 November 2026, each verified against its source and each
with its source printed beside it. Pure Python standard library renderer
(no Pillow): bitmap fonts, a raw-RGB still blitter, a small canvas and a
PNG encoder. Navy, parchment, crimson and gold: a masthead naming the
day, a hero story (Russia launches 96 drones at Ukraine overnight) with
its toon illustration, seven illustrated features in a 4 + 3 grid (the
Houthi strike on Riyadh's PIF Tower, Nvidia's 8% fall, oil at
three-month lows, the Nepal earthquake, China's probe of its Shanghai
party chief, the Thanksgiving travel storms, the UNRWA aid worker
killed in Jabalia), and the full numbered list of all 40 stories. The
eight illustrations are toon stills rendered from a Remotion + Three.js
engine, each a different scene. Fully deterministic — two runs write
byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `output/`.
